## Model and correct responsibilities

- **Python Nightshift:** single source of truth for approved task, runner state, allowlist, host acceptance, local commit and morning report. Do not turn Herdr into a second task-state writer.
- **Herdr:** visible terminal workspace, panes, live agents, status, prompt and handoff surface. Existing Herdr instance/server; don't install a parallel server.
- **Seat = named agent process + real underlying CLI identity/config + one worktree + active task or idle state.** Pane labels alone do not prove a separate AGY account or running model.
- **Operator seat:** existing Codex High / Herdr owner control pane; not an unattended worker.
- **Builder seats (to verify and add one by one):** `agy-rohit`, `agy-manickam`; each should map to its *actual* existing authenticated AGY CLI profile or report `UNVERIFIED`. Do not assume two panes mean two authenticated accounts.
- **Reviewer seat:** Codex/Sol (actual CLI/model/profile must be proven on host); user decides when independent review is worth quota.
- **Log/status pane:** tail approved runner log/JSON task state; *not* misrepresented as an interactive agent.

Herdr supports workspace/tab/pane layout and named interactive agents; locally verify command semantics via `herdr --version`, `herdr agent start --help`, `herdr agent list`, `herdr agent prompt --help`, and `herdr agent wait --help`. Current published docs:
https://herdr.dev/docs/agent-automation/ and https://herdr.dev/docs/cli-reference/
Names like `agy-rohit` are *agent labels*; only a real configured profile makes one a distinct AGY identity.
